# Clamp list to terminal height; show "not tall enough" message

## Summary

`View` (main.go) prints the banner (header), **every** visible window title,
and the help/filter footer. When many Alacritty windows are open, the output
exceeds the terminal height: rows scroll off screen, the footer becomes
invisible, and the cursor can move to entries the user cannot see.

The header and footer occupy fixed lines and must always remain visible, so
only the list of window titles may be shortened.

## Proposed behavior

- On each render, compute the available height for the list by measuring the
  actual rendered header and footer strings (counting newlines) and subtracting
  from terminal height. This adapts automatically if the banner or footer
  changes size — no hardcoded line counts.
- If the number of visible rows exceeds the available height, render only a
  scrolling subset, keeping the cursor row on screen (cursor never hidden);
  show more/less indicators (e.g. `... N more above/below ...`) so the user
  knows the list is truncated.
- If the window is too small to fit even the header and footer (i.e. the
  available height is below a minimum, e.g. < 1 row), print a message like
  `window not tall enough` instead of the list.
- Handle a height of 0 (or missing resize messages) with a sensible fallback
  so the picker still renders on the first frame.
- Truncation is display-only; filtering and cursor logic keep operating on
  the full set of rows.

## Acceptance criteria

- [ ] With more windows than fit the terminal, the header, footer, and
      cursor row are all visible; scrolling keeps the cursor in view.
- [ ] Truncation indicators show when rows are hidden above and/or below.
- [ ] Up/down navigation scrolls the window once the cursor reaches the
      truncated edge.
- [ ] When terminal height cannot fit header + footer alone, the list is
      replaced by a `window not tall enough` message.
- [ ] Resizing the terminal updates the truncation on next render.
- [ ] Filtering behavior and `-title` matching are unaffected.
