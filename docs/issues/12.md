# Add `-title` flag to raise a given window directly

## Summary

Today, `atty` always opens the interactive window picker: it lists all Alacritty
windows, lets the user filter, and raises the selected one.

Sometimes the user already knows exactly which window they want (for example
when writing a shell alias or keybinding). In that case the picker is
unnecessary overhead.

Add a `-title` flag. When given, `atty` raises the Alacritty window whose title
matches the provided value and exits, without showing the interactive picker.

Example:

```
atty -title "my project shell"
```

## Acceptance criteria

- [ ] `atty -title "foo bar"` raises the Alacritty window titled `foo bar` and exits, without starting the interactive picker.
- [ ] The value passed to `-title` may contain spaces and arbitrary text.
- [ ] The raise is recorded in the history (recency ranking) exactly like an interactive selection.
- [ ] `-no-close` does not applies in `-title` mode.
- [ ] If no window matches the given title, `atty` exits with a non-zero status and a clear error message on stderr.
- [ ] `atty -title` without a value fails with a flag-parsing error (standard `flag` behavior).
- [ ] `-info` behavior is unchanged.
- [ ] Existing interactive behavior (no flag) is unchanged.
